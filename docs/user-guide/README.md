# User guide

A practical walkthrough of Stories Engine for **authors** — no programming required. If you're a
developer looking to extend the engine itself, see [Architecture](../architecture.md) and
[Building a native app in code](../creating-custom-apps.md) instead.

1. **[Getting started](getting-started.md)** — installing the app, opening or creating a project,
   the editor's layout, running the phone preview.
2. **[Writing chapters](writing-chapters.md)** — the chapter graph, the timeline and its entry
   types, contacts, threads, groups, seed content, endings.
3. **[Conditions, flags, and reactions](conditions-and-flags.md)** — flags, requires/effects,
   events, interactions.
4. **[Custom apps (no-code)](custom-apps-nocode.md)** — building your own phone app out of visual
   blocks, no coding involved.
5. **[Assets, sound, and translations](assets-and-translations.md)** — images/audio, the sound
   catalog, music, narrative translations, the mature-content warning.
6. **[Building and exporting](building-and-exporting.md)** — the build assistant, desktop and
   Android exports, the LAN phone preview, cloud sync.
7. **[Publishing checklist](publishing-checklist.md)** — what to check before you ship.

Read them in order if you're new to the tool; jump around if you already know what you're looking
for. Every page cross-links to the ones it depends on.
